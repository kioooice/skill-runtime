# Code Of Conduct

## Our Standard

This project should be a practical and respectful place for maintainers, users, and contributors.

Expected behavior:

- be direct, constructive, and specific
- assume good faith while still checking technical claims
- keep discussion focused on the project and its users
- give actionable feedback instead of personal criticism
- respect privacy, credentials, and maintainer time

Unacceptable behavior:

- harassment, threats, or personal attacks
- discriminatory language or conduct
- publishing private information without permission
- pushing unsafe automation, credential exposure, or destructive changes
- repeatedly derailing technical discussions after maintainers have set scope

## Scope

This code of conduct applies to project spaces including issues, pull requests, discussions, documentation, demos, and maintainer communication related to the project.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues or pull requests; block users; or take other reasonable action when behavior harms the project or its contributors.

Enforcement should be proportional, documented where appropriate, and focused on keeping the project usable and safe.
